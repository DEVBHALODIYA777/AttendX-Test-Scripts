# AttendX Test Scripts

## Project Description
This repository contains sample test scripts for the AttendX student attendance application.

## Files
- `login_test.py`: Demonstrates valid and empty login input checks.
- `attendance_test.py`: Demonstrates attendance marking and invalid status checks.

## Technology Used
- Python
- Git
- GitHub
- Visual Studio Code

## Purpose
Version control is used to track changes, maintain the history of test scripts, and support collaboration among QA engineers.
